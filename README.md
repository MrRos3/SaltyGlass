# SaltyGlass

The original SaltyGlass Roblox glass UI by **MrRos3**. This repository keeps the original visual design only.

## Original
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MrRos3/SaltyGlass/main/latest.lua"))()
```

## Original + feature pack
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MrRos3/SaltyGlass/main/feature-pack.lua"))()
```

The feature pack adds Player, World, and Utility features to the original UI. The World tab uses the original tab chrome and the original UI click/hover sounds.
